Struk/nota dan laporan bisa printer berbeda. QZ Tray mencetak langsung tanpa dialog browser.

QZ Tray

  1. Pasang dan jalankan QZ Tray di komputer kasir (PC), bukan HP.
  2. Bukan Task Manager Windows (Ctrl+Shift+Esc). Cari ikon QZ di baki sistem: pojok kanan bawah, dekat jam. Kalau tidak kelihatan, klik panah ^ (Show hidden icons).
  3. Klik kanan ikon QZ (printer hijau) → Advanced → Site Manager.
  4. Tombol + → Create New → Yes → Yes → Yes (izinkan UAC).
  5. Di Desktop muncul folder QZ Tray Demo Cert. Unggah kedua file itu di bawah (digital-certificate.txt dan private-key.pem).
  6. Validasi QZ Tray. Baru sekarang centang Remember this decision lalu Allow — sekali, tidak muncul lagi.

Jika ikon QZ tidak ada: Start → ketik QZ Tray → buka. Remember terkunci jika kunci di aplikasi bukan kunci Site Manager di PC ini. Jangan campur dengan override.crt lama.
